# 다음 단계 구현 계획 (2차)

## 1. 목표
- Playwright E2E로 핵심 플로우 자동 검증
- 모바일 터치 드래그앤드롭 강화
- 사운드 on/off 설정
- 접근성 개선(키보드 조작, 포커스, ARIA)
- 교사 패널 레벨 미리보기/테스트 실행
- 조건/반복 심화 레벨 추가

## 2. 구현 단계
1. E2E: Playwright 설치, 기본 시나리오 작성, CI 연동
2. 터치 DnD: 포인터 드래그 오버레이, 탭 추가 폴백, 터치 타겟 확대
3. 사운드 설정: localStorage 저장, 토글 UI, 유틸 반영
4. 접근성: 블록 키보드 이동/삭제, 포커스 링, ARIA 라벨
5. 교사 미리보기: 격자 미리보기, 시작 방향, 테스트 실행 버튼
6. 레벨 확장: ifObstacle 중심 레벨 3개 추가

## 3. 검증
- `npm run test`
- `npm run build`
- `npx playwright test`
