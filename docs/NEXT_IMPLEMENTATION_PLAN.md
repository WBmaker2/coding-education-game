# 다음 단계 구현 계획

## 1. 목표
- 모바일 터치 드래그앤드롭 지원 강화
- 레벨 완료 E2E 테스트 자동화
- 교사 패널 시각 레벨 편집기(격자 클릭으로 장애물/목표 배치)
- 실행/성공/실패 사운드 및 햅틱 피드백
- 접근성 개선(키보드 조작, 포커스, ARIA)

## 2. 구현 단계
1. 터치 DnD: Pointer Events 기반 드래그, 길게 누르기 이동, 폴백 버튼
2. E2E: Playwright 시나리오(레벨 선택→블록 조합→실행→성공 모달)
3. 시각 편집기: 격자 셀 클릭으로 장애물/목표/시작 위치 설정, JSON 동기화
4. 사운드: Web Audio API 효과음, prefers-reduced-motion 대응
5. 접근성: 키보드로 블록 추가/이동/삭제, 포커스 링, 스크린리더 라벨

## 3. 검증
- `npm run test` 단위 테스트
- `npm run build` 빌드
- E2E 스모크 테스트
